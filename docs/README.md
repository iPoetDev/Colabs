# Colabs Documentation

Documentation for setting up and using a local Python + Jupyter environment with
Google Colab, organised by the [Diátaxis](https://diataxis.fr/) framework. Each
document serves exactly one reader need — start with the one that matches yours.

## Start here

**Complete beginner?** Start with the [Getting Started guide](how-to/getting-started.md).
It walks you through installing every tool and running your first notebook, step by step —
no prior experience required.

## Reading order

1. **Brand new?** → [Getting started](how-to/getting-started.md) — install everything and run your first notebook.
2. Environment working → follow the **Tutorial** for a deeper walkthrough.
3. Need a specific task → jump to the relevant **How-to**.
4. Hit an error → check [Troubleshooting & gotchas](how-to/troubleshoot-uv-jupyter-colab.md).
5. Need exact package names or commands → consult the **Reference**.

> Documents link *across* quadrants rather than repeating each other. If a Tutorial
> step needs a full option table, it links to the Reference instead of embedding it.
